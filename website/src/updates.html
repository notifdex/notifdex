Updates

What’s new in Notifdex for macOS. Update anytime with brew update && brew upgrade --cask notifdex, or browse full commit details on GitHub Releases.

v0.2.0 November 27, 2026

Opt-in private iCloud sync with Notifdex for iPhone

  • Added optional, opt-in private iCloud sync (iCloud.com.notifdex.shared) between Notifdex for macOS and the new Notifdex iOS companion app, keeping Inbox triage, flags, follow-ups, People, and Notes in sync across devices while keeping hidden/muted Mac alerts strictly local.
  • Automatic bidirectional sync runs on local edits, app wake, periodic checks, and silent CloudKit push notifications, with live Inbox updates and one-tap device revocation in Recovery → iOS & iCloud Sync.
  • Added cross-device duplicate collapsing so notifications captured both on iPhone and via macOS forwarding appear once in Inbox with clear source labels, and triage actions stay in sync across paired copies.
  • Added macOS iPhone-forwarding health diagnostics and recovery guidance when macOS drops forwarded alerts for an iPhone-only app (see the FAQ).
v0.1.5 November 25, 2026

Custom apps in People handle pickers

  • Apps you add in Apps, such as WeChat, and apps Notifdex has seen in notifications now appear as platform options when you add a handle in New Person…, the contact card, or People.
v0.1.4 November 25, 2026

Contact cards & smoother dragging across displays

  • Inbox now suggests possible contact matches in the alert detail pane. Create a person or link an existing one there, then open the contact card to edit handles, manage workspaces, or add a note.
  • People has a searchable person switcher, and handles keep the capitalization you enter.
  • Fixed App Center jumping or drifting away from the pointer when you drag it between displays.
  • Added the FAQ and this release history to notifdex.com.
v0.1.3 November 25, 2026

Open Apple Messages directly from Inbox

  • Added an Open in Messages button on captured Apple Messages alerts so you can jump straight into Messages.app without opening a blank compose draft.
v0.1.2 November 25, 2026

Cleaner macOS 26 titlebar & smooth multi-monitor dragging

  • Removed the automatic glass bubble around the Notifdex icon and wordmark in the titlebar on macOS 26.
  • Fixed an awkward jump to the screen edge when dragging App Center across monitors by deferring window chrome updates while a drag is in progress and preventing drag releases from firing titlebar double-click zoom.
v0.1.1 November 24, 2026

Cleaner Homebrew cask & setup guide

  • Removed the deprecated Homebrew depends_on macos: string warning so installs and upgrades run cleanly.
  • Updated the install guide and homepage with Homebrew instructions and a clearer first-time checklist for iPhone notification forwarding.
v0.1.0 November 24, 2026

First signed, notarized macOS release & Homebrew tap

  • Published Notifdex’s first Apple Developer ID–signed and notarized universal Mac app (Apple Silicon + Intel) on GitHub Releases and via brew install --cask notifdex/tap/notifdex.
  • Signed builds share a stable identity so macOS Accessibility permissions carry across upgrades instead of resetting on every rebuild.
  • Includes local SQLite capture for Mac and forwarded iPhone notifications, Inbox search and triage, People profiles across workspaces, Today follow-ups, personal and shared notes, Notification Center Recovery, and Glass/Solid themes.
